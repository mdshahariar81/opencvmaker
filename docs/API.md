# OpenCVMaker — API Documentation

## 1. API Overview

The OpenCVMaker API provides backend services for authentication, CV management, templates, exports, subscriptions, usage tracking, and administration.

The API is designed to be consumed by the OpenCVMaker web application and future clients.
