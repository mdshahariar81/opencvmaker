# Code of Conduct

## Our Commitment

OpenCVMaker is committed to providing a welcoming, respectful, inclusive, and harassment-free environment for everyone.

This Code of Conduct applies to all contributors, maintainers, users, reviewers, and community members.

## Expected Behavior

Participants are expected to:

- Be respectful and professional.
- Communicate constructively.
- Welcome different perspectives.
- Give and receive constructive feedback.
- Focus on ideas and technical problems rather than individuals.
- Respect other contributors and their time.
- Help maintain a positive open-source community.

## Unacceptable Behavior

The following behavior is not acceptable:

- Harassment or discrimination.
- Personal attacks.
- Threats or intimidation.
- Trolling or deliberately disruptive behavior.
- Sexual harassment.
- Publishing private information without permission.
- Malicious behavior toward contributors or users.
- Abuse of project infrastructure.
- Any other behavior that creates an unsafe or hostile environment.

## Technical Discussions

Technical disagreements are normal in open-source development.

When disagreements occur:

1. Focus on the technical problem.
2. Explain your reasoning clearly.
3. Consider alternative approaches.
4. Avoid personal attacks.
5. Respect maintainers' decisions when appropriate.

## Enforcement

Project maintainers may take appropriate action when this Code of Conduct is violated.

Possible actions include:

- Warning
- Removal of inappropriate content
- Temporary restriction
- Temporary suspension
- Permanent removal from project participation

Actions will depend on the severity and circumstances of the violation.

## Reporting

If you experience or witness unacceptable behavior, report it privately to the project maintainers.

Do not publicly expose sensitive personal information while reporting an incident.

## Scope

This Code of Conduct applies to:

- GitHub repositories
- Issues
- Pull requests
- Discussions
- Documentation
- Community channels
- Other official OpenCVMaker project spaces
